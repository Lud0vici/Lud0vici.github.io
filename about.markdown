In the meantime, I'm also building this website for fun — both as a professional portfolio and as an authentic blog to share my journey.

- **Languages**: Python, C, Bash, OCaml, Assembly (Tiva C microcontrollers), Scala

- **Web**: HTML, CSS, JavaScript, ReactJS, some Jekyll

Right now, I'm reading *Cyberpunk 2077: No Coincidence* by Rafał Kosik.
